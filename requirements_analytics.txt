# The analytics pipeline is lightweight and only requires:
#   - requests:       Fetch data from Binance API
#   - pandas:         Data manipulation (DataFrames, datetime handling)
#   - supabase:       Database operations
#   - python-dotenv:  Load environment variables from .env file
#
# It does NOT require:
#   - ta (technical analysis library) - EMAs calculated manually with pandas
#   - numpy - pandas handles all numeric operations
#   - scikit-learn - no ML training in this pipeline
#   - matplotlib/plotly - no visualization
#
# Total install size: ~50 MB (very small)
# Install time: ~30 seconds
